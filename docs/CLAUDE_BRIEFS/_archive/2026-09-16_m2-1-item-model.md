## Data & rules
1. Rarity ladder = 7 (`Common…Mythic`), `Fine` → `Uncommon` with a save migration. Item shape `{id, kind, type, tier, rarity, rating, empower, name}`; `kind` ∈ weapon | armor | core | material. Tier table §1 in `data.js`.
2. Two-axis power in `derive.js`: `base(type) × tierMult × rarityMult × ratingScale × empowerScale` (weapons) and armor HP/mit with tier+rarity. Tests: a T5 Common beats a T1 Artifact; rating/empower scales as before.
3. Loot: normal nodes Common→Epic weighted by area; rares/bosses roll up to Artifact with §1 weights, boss +1 step / rating floor 40, Attune Vein doubling top-two; tier = area tier. Tests for each.
4. Craft gating: materials/armor rarity cap by area (≤Epic anywhere; Legendary 6–7; Artifact 8–9; Mythic 10). Cores: `Artifact Core` (drop from rares/bosses + gather in 8–9), `Mythic Core` (Vaelyx). Smith gets an **Upgrade grade** flow: Legendary + Artifact Core + zone mats → Artifact; Artifact + Mythic Core → Mythic; rating/empower carried. Rates DESIGN-OPEN placeholders.
5. Weapon special names: name tables **per type per tier** in `data/weaponNames.js` (`{ [type]: { [tier]: [4 names] } }`). Design Chat supplies the 224 names; until then use one placeholder per type per tier (`"<Type> of T<n>"`), marked DESIGN-OPEN.
6. Train cap at the highest roster level (§7), slot message "At roster cap — climb the mountain". Test.

## UI
7. `ItemRow` (name in rarity colour · `[T3]` · `[Rare]` · `[72]` · `+N` · "Equipped · Kessa") and `ItemSheet` (special name + plain name header; Attack Power / Attack Speed / Mitigation / Bonus stats; **Equip · Compare · Empower · Sell**; no scrap). Sheets inherit mode (Style Bible §D). Replace every existing item rendering with these.
8. **Bag screen** (§5): Town row "Bag" replaces the stash list; filter chips All/Weapons/Armor/Cores/Materials; sort Rating/Rarity/Newest; long-press bulk Sell with confirm skipping equipped.
9. **Character sheet** (§6): six premade slot icons (add `icon-slot-weapon/body/head/hands/feet/gem.png` to the art manifest; placeholders until art), rarity-tinted border + rating when filled, greyed "nothing equipped" when empty; filled tap → ItemSheet; empty tap → bag filtered to slot with Compare; gem slot "Coming — not yet active"; header with the 9 derived stats.
10. Helm/Gauntlets/Greaves recipes at every craftable rarity (½ body values).
11. Roster (§8): Recruit row + panel (three daily candidates; cost placeholder DESIGN-OPEN), bench rows with Hearth job, rename, dismiss (gear to bag).
12. Results: loot lines as ItemRow with "↑ upgrade for <name>" when it beats the equipped item's derived contribution.
